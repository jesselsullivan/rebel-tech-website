The Rebel Tech logo/favicon is provided as a transparent SVG.

The existing Rebel Tech hero artwork and angled service-van image are loaded from the public GitHub repository so the ZIP stays lightweight. The site applies transparent/masking-style presentation so the rectangular photo backgrounds do not dominate the layout.

The homepage hero uses a looping Pexels networking/cable MP4 as the moving background, with a dark overlay so the Rebel Tech branding remains readable.

IMPORTANT: On first run, use START-REBEL-TECH.bat or run `npm install` before `npm run dev`. The project now automatically checks for Bootstrap and Material UI dependencies before `npm run dev` and `npm run build`, so a stale node_modules folder will be repaired automatically.
